# Military Prime Website

A standalone, responsive website built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The site links to the live rental application and resident/owner portals. The contact form prepares an email in the visitor's default mail app; it does not submit data to a server.
